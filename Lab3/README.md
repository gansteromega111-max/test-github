# Лабораторная работа №3. Условные операторы. Реализация алгоритмов ветвления

Решения задач базового уровня (А) по дисциплине «Основы программной инженерии»:

- **A1.py** — Программа определяет, лежат ли две введенные точки в одной координатной четверти, и выводит номер четверти.
- **A2.py** — Программа выполняет комплексную проверку введенного пароля на соответствие требованиям безопасности и выдает список допущенных ошибок.
- **A3.py** — Программа рассчитывает объем потребленного газа по показаниям счетчика (с учетом возможного сброса при достижении 10000), общую стоимость по тарифной сетке и среднюю цену за кубометр.
